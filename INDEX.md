## 📱 Documentation Format

All documentation is provided in Markdown format (.md) for easy reading and version control.

### How to Read
- Use any text editor or Markdown viewer
- GitHub automatically renders Markdown
- VS Code has built-in Markdown preview

### How to Search
- Use Ctrl+F (Cmd+F on Mac) to search within documents
- Use grep to search across files:
  ```bash
  grep -r "search term" .
  ```
